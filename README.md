# GitHub Copilot Neon Drift

A fast neon arcade game built as a GitHub Copilot extension canvas.

Dash through danger, earn Overdrive energy from near misses, and activate a timed double-score burst while a path-aware obstacle planner keeps every red-barrier sequence traversable.

## Install

**Use this exact extension-folder URL:**

https://github.com/davidkaya/github-copilot-neon-drift/tree/main/.github/extensions/neon-drift

The repository root URL is **not** a supported GitHub Copilot extension install source and will not install Neon Drift. The installer URL must point directly to the folder containing `extension.mjs`.

In GitHub Copilot:

1. Open the command palette and choose **Install extension from URL**.
2. Paste the exact folder URL above.
3. Select **User** scope so Neon Drift is available across projects.
4. Reload extensions if prompted, then ask Copilot to open canvas ID `neon-drift`.

See the [extension README](.github/extensions/neon-drift/README.md) for controls and architecture.
